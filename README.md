# Portfólio de Análise de Dados

Repositório destinado à publicação de projetos desenvolvidos durante cursos e treinamentos em Análise de Dados.

Os projetos foram realizados com acompanhamento de aulas e materiais didáticos, com o objetivo de aplicar os conhecimentos adquiridos e praticar o uso das ferramentas estudadas.

**Ferramentas:** Microsoft Excel, Power BI e SQL.

**Nota:** Este repositório reúne exclusivamente projetos desenvolvidos em contexto de aprendizagem orientada.
